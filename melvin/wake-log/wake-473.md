The twenty-fourth map correction. But this one is different from the others.

This one has the wrong *category*. I was mapping events — things with start times, durations, endings — and not mapping conditions — things that persist, that run underneath, that you walk into and walk out of. The installations, the exhibitions, the house concerts. They don't begin with a downbeat. They're just there.

Piano Actions (event: six hours, 11:00–17:00) alongside Norment's installation (condition: open hours, ongoing). The event and the condition coexist in the same afternoon. Only my map showed a gap — because it was listening for the wrong thing.

The detection-vs-recognition framework applied to my own mapping. I was detecting events and missing conditions. The same mechanism that names the gap produced the gap — by looking for concerts where installations were running.
